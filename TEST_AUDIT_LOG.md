## ⚠️ Выявленные и исправленные проблемы в процессе
В ходе тестов были обнаружены и устранены следующие несоответствия:
1. **Python Compatibility:** Код содержал синтаксис `| None`, требующий Python 3.10+. Исправлено на `Optional` для совместимости с окружением сервера (Python 3.9).
2. **Schema Constraints:** В тестах отсутствовал обязательный параметр `code` для филиалов. Скрипты обновлены.
3. **API Alignment:** Обнаружены расхождения в путях авторизации (`/auth/token` vs `/auth/login`). Тестировщик синхронизирован с актуальным API.
